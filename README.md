# Nodelizr

Nodelizr is an open-source Node.js project generator. It provides a visual interface for configuring projects, selecting dependencies, previewing the generated structure, and downloading a ready-to-use ZIP file.

[Open Nodelizr](https://nodelizr.vercel.app)

## Features

- Generate Express, Fastify, CLI, and worker projects
- Start from predefined templates or create a custom setup
- Select dependencies through a searchable interface
- Preview files and folder structure before generation
- Download the generated project as a ZIP file

## Technologies

- Next.js 16 (App Router) and React 19
- TypeScript
- Tailwind CSS 4
- shadcn/ui
- Zustand

## Getting started

### Prerequisites

- Node.js 20.9 or later
- npm

### Installation

```bash
git clone https://github.com/Aethelon/Nodelizr.git
cd Nodelizr
npm install
npm run dev
```

The application will be available at [http://localhost:3000](http://localhost:3000).

## Scripts

| Script | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm run start` | Serve the production build |
| `npm run lint` | Run ESLint |
